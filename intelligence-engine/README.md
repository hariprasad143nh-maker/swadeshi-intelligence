# Intelligence Engine Module (intelligence-engine)

**Owner:** Member 3 (Intelligence & Analytics Lead)  
**Assigned AI Assistants:** Claude / ChatGPT  

## Purpose
The Intelligence Engine houses the analytical core of Swadeshi Intelligence:
1. **Cost Competitiveness Modeling:** Computes landed import costs vs estimated domestic production costs.
2. **Opportunity Ranking Engine:** Ranks candidate products using a multi-factor scoring formula.
3. **Feasibility Evaluator:** Evaluates agro-climatic requirements, infrastructure readiness, and capital expenditure barriers.
4. **Recommendation Generator:** Produces actionable strategies tailored to Farmers, MSMEs, Manufacturers, and Policymakers.

## Testing & Quality
Member 3 must maintain independent unit tests in `intelligence-engine/tests/` verifying all mathematical formulas and edge cases (e.g., zero import values, negative savings).
